# RideWise Frontend

This directory contains the React 19 + Vite 8 + Tailwind CSS + Leaflet SPA for RideWise.

For full setup, architecture, API, and deployment guides, see the root documentation:

- [Root README](../README.md)
- [Setup & Troubleshooting Guide](../docs/SETUP.md)
- [API & Environment Reference](../docs/API.md)

## Scripts

```bash
npm run dev      # Start Vite dev server on http://localhost:5173 (proxies /api and /ws)
npm run build    # Build production bundle to dist/
npm run preview  # Preview the production build locally
npm test         # Run native node --test suites in tests/
npm run lint     # Run ESLint across the frontend
```
