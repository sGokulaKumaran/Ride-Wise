  Purpose : This component provides a full-screen navigation overlay displayed during an active ride or when viewing past rides. It integrates a live GPS-tracked MapLibre map, turn-by-turn instructions, and ride metrics, giving the user a Google Maps-style navigation experience.
================================================================================

  KEY CONCEPTS IN THIS FILE
  -------------------------
  1. Map Overlay UI: A full-screen or minimized view to track ride progress.
  2. GPS Integration: Live location tracking using watchLocation to update the user's position and speed.
  3. Route Calculation: Updating the remaining distance and time based on the active step and haversine calculations.
  4. View-Only vs Active Mode: Behavior changes depending on if a ride is live (requires GPS and End button) or historical.
  5. Step Management: Parsing and tracking the active step in a route to show the correct maneuver instructions.

================================================================================
  HOW THIS FILE CONNECTS TO THE REST OF THE APP
================================================================================
ActiveRideOverlay is a critical, immersive view within the frontend application. It acts as the primary screen once a ride is started, blocking out the rest of the application to focus the user entirely on navigation. It orchestrates several distinct pieces:
1. `RideMap`: Contains the actual map rendering logic.
2. `DirectionsPanel`: Provides the detailed list of maneuvers.
3. Services (`locationService`, `routingApi`, `rideApi`): It heavily relies on background services to grab device GPS updates, calculate haversine distances, format API data, and constantly ping the backend with the user's latest location via `updateUserLocation`.
