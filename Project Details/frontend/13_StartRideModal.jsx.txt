  File    : StartRideModal.jsx
  Located : E:\My projects\RideWise\frontend\src\pages\components\shared\StartRideModal.jsx
  Purpose : This file renders a slide-up modal used to initiate and configure new rides (either solo or group). It manages an internal state machine (screens: home, type, setup) and serves as an entry point to the RideSetupFlow. When a ride is successfully configured, it triggers a callback to close itself and display the active ride map in the main application.
================================================================================

  KEY CONCEPTS IN THIS FILE
  -------------------------
  1. Internal State Machine: Uses a 'screen' state to navigate between Home, Type selection, and Setup screens inside the modal without changing routes.
  2. Overlay & Backdrop: A typical modal structure with a semi-transparent backdrop and a styled container that slides up from the bottom (mobile-friendly).
  3. Callbacks to Parent: Communicates user actions (ride created, history opened) back to the parent Home.jsx via props.

================================================================================
  HOW THIS FILE CONNECTS TO THE REST OF THE APP
================================================================================
- It acts as the gateway to starting any new ride, wrapping the `RideSetupFlow` component which handles the actual map routing and data fetching.
- It is mounted conditionally in `Home.jsx` when the user clicks the "Start Ride" floating action button.
- Upon a successful setup in `RideSetupFlow`, it triggers the `onRideCreated` callback, passing the fully formed ride object back up to `Home.jsx`. `Home.jsx` then unmounts this modal and mounts the full-screen `ActiveRideOverlay`, completing the transition from "planning" to "riding".
