================================================================================
  RIDEWISE PROJECT -- CODE EXPLANATION
  File    : useTheme.js
  Located : E:\My projects\RideWise\frontend\src\pages\hooks\useTheme.js
  Purpose : This file creates a custom React hook that manages the visual styling (themes) of the app. It holds definitions for different themes (dark, light, warm, midnight) and automatically applies one based on the time of day or the user's saved preference.
================================================================================

  KEY CONCEPTS IN THIS FILE
  -------------------------
  1. Custom Hook: A reusable function (`useTheme`) that shares logic across React components.
  2. Tailwind CSS Objects: Storing utility classes inside a JavaScript object to easily switch the entire app's look.
  3. Local Storage: Using the browser's memory to remember the user's chosen theme.
  4. Time-based Logic: Automatically calculating the best theme using the current hour.
