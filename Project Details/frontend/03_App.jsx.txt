  KEY CONCEPTS IN THIS FILE
  -------------------------
  Routing: The system that changes what is on the screen when the web address changes, without reloading the whole page.
  Context Providers: Special wrappers that share data (like user login status) with every page inside them.
  Protected Routes: Special pages that check if a user is allowed to see them (like if they are logged in) before showing up.
